# M10 hero headline study

Three candidates were rendered in the built hero with the same lead, CTA and plates, at 1440×900, 390×844 and
320×568 (`hero-title` text swapped in the page, then measured). Line counts and positions are measured, not
estimated.

| | Candidate | Lines at 1440 / 390 / 320 | Plates start (1440 / 390) | Clarity | Specificity | Credibility | Fit with the plates |
|---|---|---|---|---|---|---|---|
| **A** | **I build software end to end.** | **2 / 2 / 2** | **312 / 328 px** | Plain, one idea | Says the scope of ownership; the lead names the four kinds of product | Every flagship is a solo build, from data model to interface | Strongest: it is the claim, and the four plates under it are the evidence |
| B | I build software people can actually use. | 3 / 3 / 3 | 389 / 368 px | Clear | Generic: true of most software | "Actually" reads defensive | Pushes the plates 77 px down on desktop; three lines on every width |
| C | From the data model to the app store. | 3 / 3 / 3 | 389 / 368 px | Clear | Very specific | Only T Poker reached a store; Aegis, DeveloperOS and GRAVITY FLOW did not, so the line overclaims for three of four plates | Same height cost as B |

**Chosen: A.** It is the only one that sets in two lines at every width, which keeps the plates highest in the first
screen (and the mobile mosaic above the fold at 390). It makes no claim the plates below it don't support, and the
lead carries the range in the four kinds of product the brief named: mobile apps, security systems, developer
tools and games.

Lead: "I'm a software engineer who designs, builds and tests mobile apps, security systems, developer tools and
games." (After review: the first version opened on a fragment, "Software engineer.") No eyebrow, no metric tiles, no
tracked labels.

## Phones: "See the work" before or after the plates

Measured in the built page (top and bottom of each block, CSS px, from the top of the screen):

| Width × height | CTA before the plates: CTA · plates | CTA after the plates: plates · CTA |
|---|---|---|
| 320 × 568 | 278–326 · 350–698 | 286–634 · **654–702 (below the fold)** |
| 360 × 780 | 254–302 · 326–724 | 262–660 · 680–728 |
| 390 × 844 | 256–304 · 328–763 | 264–699 · 719–767 |
| 430 × 932 | 259–307 · 331–817 | 267–753 · 773–821 |

**Chosen: before.** The action stays in the first screen at every width, including 320 × 568, and the plates still
sit fully in view from 360 up. Placed after, the plates rise only 64 px but the action drops out of the first screen
on the smallest phone. The gap between the action and the first plate is 24 px, so the button never touches a card.
