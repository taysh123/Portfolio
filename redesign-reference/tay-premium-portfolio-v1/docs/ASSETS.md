# Assets

## Existing project screenshots

The current portfolio repository already contains the real project screenshots used by the redesigned scenes.

Run:

```bash
npm run sync:assets
```

This downloads the project media directly from the public `taysh123/Portfolio` repository into matching paths.

## Concept art

`docs/portfolio-concept.png` is the approved visual direction collage generated during the redesign discussion. It is reference material, not a production page background.

## Intro desk

The desk, monitor, laptop, notebook, mug, keyboard and lighting are generated entirely from CSS/DOM. There are no stock image licensing dependencies in the intro.
