# The Night Studio — the About photograph (M10)

> **Retired from the page (2026-10-13).** The owner rejected this render as About's visual; About now lays out
> four real product captures in HTML and CSS (`components/sections/AboutVisual.tsx`), and `public/work/about-studio-*`
> is gone. This folder stays as the scene's source only; nothing in it is served, and `about-photo.mjs` would
> recreate files the page no longer uses.

The source for the page's one photograph: a developer's desk at night with the four flagship products running on
real devices, shown in About with the caption "Where the work happens". It is a still: M10 retired the M9 hero's
real-time WebGL layer (`lib/studio`, `public/studio` and three.js are gone), so nothing here runs in the browser.
Everything is built from code — no downloaded models, textures or HDRIs, and nothing from the frozen Entrance V2 work.

| File | What it is |
| --- | --- |
| `scene_b.py` | The Blender scene used for the photograph ("Night Studio 2.0": brighter screens, a smaller unlit plaque, the GRAVITY FLOW phone on its own stand). Camera, exposure, screen emission and lamp are environment parameters (`B_CAM`, `B_EXP`, `B_SA`, `B_SD`, `B_LAMP`, `B_WW`, `B_SIGN`) |
| `scene.py` | The M9 scene it was derived from, kept for reference |
| `prep_screens_b.py` | Cuts the screen textures from the portfolio's own captures (crops and resizes only) |
| `prep_brand.py` | Prepares the T Poker plaque artwork from the owner's original files in `brand/src/`, cropped and keyed but never redrawn |
| `sign_b.json` / `sign.json` | The plaque module (artwork, position, size, light) for the M10 and M9 scenes |
| `about-photo.mjs` | Crops the render to the products and the plaque, grades it for a light page (a stop brighter, slightly warm) and writes AVIF/WebP to `public/work/` |
| `render.sh` | Runs everything above, in order |

## Re-rendering

```sh
BPY=/path/to/python-with-bpy design/studio/render.sh /tmp/studio-build 40
```

The committed photograph was rendered at 2880×1800, 40 spp, with
`B_CAM={"loc":[0.18,-1.40,0.70],"target":[0.70,0.12,0.27],"lens":31,"shift":[-0.20,0.03]}`, `B_SA=2.6`, `B_SD=2.4`,
`B_LAMP=34`, and Aegis's texture from the owner's original PNG capture of its Incidents page (`AEGIS_ORIG`, required:
the full captures are not public). AgX "Medium High Contrast", exposure 0.4.
On the 4-core container it was made on, the render takes about 6 minutes.

## The T Poker plaque (`sign_b.json`)

- **Artwork:** the official app icon and the "T POKER" wordmark, taken from the owner's original files.
  - `brand/src/tpoker-app-icon-1024.webp`: the icon is cropped to its alpha bounds.
  - `brand/src/tpoker-banner-1024x500.png`: the wordmark is cut out of the banner. The navy gradient behind it is
    estimated and removed, so the letters keep their exact shapes, colours and anti-aliasing.
  - Both are shown at their own aspect ratios; nothing is redrawn, recoloured or stretched.
- **Lighting:** in the M10 scene the plaque is unlit (`light_watts` 0) and smaller, so it reads as a sign on the wall,
  not a spotlit logo; a faint wall wash keeps the back wall visible behind it.
- **Changing it:** edit `sign_b.json` (size, position, artwork paths, light), then re-render with `render.sh`. No scene
  code changes.
- **Generated files:** `brand/tpoker-icon.png` and `brand/tpoker-wordmark.png` are generated by `prep_brand.py` and
  are not committed.
